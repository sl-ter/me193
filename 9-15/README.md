# 9/15 — Grayscale

Image processing exercise: convert an image to grayscale.

- `grayscale.py` — loads an image and converts it to grayscale using [Pillow](https://pillow.readthedocs.io/), saving the result alongside the original, tagged with today's date (`<name>_9-15_grayscale<ext>`).

## Run it

From the repo root, with the venv active (see root [README](../README.md)):

```bash
python 9-15/grayscale.py path/to/image.jpg
```
